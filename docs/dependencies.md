## External runtime services

- Python Studio loads Pyodide 0.26.4 and Python scientific packages from jsDelivr. See the Pyodide distribution and each Python package for their license notices.
- Gemini is an optional external API. Browser voice features use device voices or the browser provider. The interface also loads Google Fonts when reachable.
- Built-in sample tables and generated examples use synthetic data. The generator downloads no external datasets.
